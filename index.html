How I work

Discover

Recordings, analytics and user interviews show where the product really breaks.

  • Clarity & GA4 review
  • User interviews
  • Competitor audit

Define

One clear problem statement, with a number the design has to move.

  • Problem statement
  • Success metric
  • User flows

Design & test

Wireframes, then UI. When unsure, two versions go in front of real users.

  • Wireframes
  • High-fidelity UI
  • Usability tests

Ship & measure

Coded prototypes and clean handoff, then back to the data to check it worked.
