# Jagdish Bisht — Product Designer Portfolio

Static portfolio site. No build step: plain HTML, CSS and JavaScript.

## Pages
| Page | File |
|---|---|
| Home | `index.html` |
| Devora — AI pricing assistant | `devora.html` |
| Match — two-sided hiring app | `matchd.html` |
| MAR — growth agency website | `mar.html` |

## Structure
```
assets/    fonts (Satoshi), icons (SVG), images
css/       style.css — all styles + design tokens
js/        script.js — nav, hero typewriter, scroll reveal
```

## Run locally
```bash
python -m http.server 5510
```
Then open <http://localhost:5510>.

## Deploy
Any static host. No framework, no build command, output directory is the repo root.
