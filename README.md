# Jagdish Bisht — Portfolio v2

Static site with no build step. Deploy this `v2/` folder to any static host (Netlify, Vercel or GitHub Pages). The output directory is the folder root.

## Pages
| Page | File |
|---|---|
| Home | `index.html` |
| Work, About, Playground | `work.html`, `about.html`, `playground.html` |
| SEO landing pages (Code Brew Labs) | `seo-landing-pages.html` |
| Devora, AI pricing assistant | `devora.html` |
| Dating & coaching app (client under NDA, logo blurred) | `dating-app.html` |
| BharatPe merchant UX research | `bharatpe.html` |
| Match (concept) | `match.html` |
| Mind Bloom (concept) | `mindbloom.html` |

## Editing case studies
Page bodies live in `../_scripts/pages/*.html`. The shared nav and footer are added by:

```bash
python _scripts/build.py
```

Run it from `portfolio-deploy/`. All pages, including the homepage, live in `_scripts/pages/`. Phone mockups are generated by `python _scripts/mockups.py`.

## Run locally
```bash
python -m http.server 5520 --directory v2
```
